# Minecraft бот 1.21.4 + Ollama

Нужен Node.js 22+ и запущенная Ollama с моделью `deepseek-coder:6.7b`:
```
ollama pull deepseek-coder:6.7b
```

## Запуск
Двойной клик по `start.bat` (или `node bot.js`).
При первом запуске бот спросит адрес сервера, ник и пароль и сохранит их в `settings.json`.
Чтобы поменять — удали `settings.json`.

Если папка без `node_modules` — сначала `npm install`.

## Команды в консоли
- `portal 1` ... `portal 8` — идти к порталу (решает ИИ, маршрут с обходом препятствий)
- можно текстом: `иди в портал 3`, `иди 10 64 -5`
- `pos` — где бот
- `stop` — остановиться
- `exit` — выйти

Порталы, задержки и команды `/reg` `/l` — в `config.js`.
