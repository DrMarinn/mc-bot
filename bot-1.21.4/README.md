# Minecraft бот 1.21.4 + Ollama

Нужен Node.js 22+ и запущенная Ollama с моделью `deepseek-coder:6.7b`:
```
ollama pull deepseek-coder:6.7b
```

## Запуск
Двойной клик по `start.bat` (или `node bot.js`).
При первом запуске бот спросит адрес сервера, ник и пароль и сохранит их в `settings.json`.
Чтобы поменять — удали `settings.json`.

Если папка без `node_modules` — сначала `npm install`.

## Команды в консоли
Пиши обычным текстом — ИИ (Ollama) поймёт и выберет действие. Без Ollama работает простой разбор.
`help` — список всех команд.

- `portal 1` ... `portal 8` — идти в портал
- `иди на координаты 77 71 -194` / `иди 77 71 -194` — идти на координаты
- `иди за Steve` — следовать за игроком (до `stop`)
- `подойди к Steve` — подойти к игроку
- `убей зомби` / `таргет Steve` — атаковать, пока цель не умрёт
- `ударь Steve` — ударить один раз
- `охраняй` — бить враждебных мобов рядом (до `stop`)
- `посмотри на Steve`, `повернись на север`
- `напиши в чат привет` — написать в чат
- `выбрось 5 dirt`, `выбрось всё`
- `возьми в руку diamond_sword` — взять/надеть предмет
- `инвентарь`, `поешь`, `подбери вещи`, `погуляй` (до `stop`)
- `сломай oak_log` — найти и сломать блок
- `прыгни 3 раза`, `присядь`, `встань`, `используй предмет`, `иди спать`
- `кто онлайн`, `где ты`, `статус`
- `stop` — остановить, `exit` — выйти

Порталы, задержки, команды `/reg` `/l` и `useAI` — в `config.js`.
